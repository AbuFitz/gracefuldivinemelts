# Graceful Divine Melts — Shopify theme

Online Store 2.0 theme (Liquid, JSON templates, sections, metafields). No build step, no hosting subscription, no apps.

- Install as an **unpublished** theme: see `docs/08-migration-and-launch-checklist.md`.
- Documentation: `docs/00` (research) … `docs/09` (customer handover), plus V2: `10` visual audit, `11` brand/media inventory, `12` design direction, `13` SEO, `14` Shopify compatibility, `15` custom scent journey, `16` QA and outstanding tasks. Screenshots: `docs/screenshots/`.
- Status (V2): Theme Check clean; 23/23 local interaction tests pass; **not yet run on a Shopify store** (see `docs/14`, `docs/16`).
- `tools/preview` is a local visual-QA harness (LiquidJS + Playwright). It is not part of the theme (`.shopifyignore`).
